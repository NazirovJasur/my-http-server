# 💰 Учёт личных трат

Учебное веб-приложение на Go для учёта личных расходов.
Реализованы **этапы 1–3**: HTML-интерфейс, полный CRUD трат и постоянное хранение в SQLite.

## Возможности

- Просмотр списка трат в таблице (ID, сумма, описание, дата).
- Добавление, редактирование и удаление трат через веб-интерфейс.
- Данные хранятся в файле SQLite и сохраняются между перезапусками сервера.
- После отправки форм выполняется redirect (Post/Redirect/Get), повторной отправки при обновлении страницы нет.
- Общий layout (шапка и подвал) для всех страниц.

## Технологии

- Go (версия не ниже 1.22, нужна для маршрутов вида `GET /add`)
- `net/http`, `html/template`, `database/sql`
- SQLite, драйвер `modernc.org/sqlite` (без CGO)
- HTML и CSS без фреймворков

## Запуск

Команды выполняются **из корня проекта** (где лежит `go.mod`): пути к шаблонам, статике и базе заданы относительно него.

```bash
go mod tidy
go run ./cmd/server
```

Откройте в браузере: <http://localhost:8080>

Чтобы начать с чистой базы, остановите сервер и удалите файл `expenses.db`. При следующем запуске таблица создастся заново.

## База данных

Таблица `expenses`:

| Поле          | Тип     | Описание        |
|---------------|---------|-----------------|
| `id`          | INTEGER | первичный ключ  |
| `amount`      | REAL    | сумма           |
| `description` | TEXT    | описание        |
| `date`        | TEXT    | дата (YYYY-MM-DD) |

Все запросы выполняются через слой репозитория с placeholder `?`, что защищает от SQL-инъекций.

Методы `ExpenseRepository`: `Create`, `GetAll`, `GetByID`, `Update`, `Delete`.

## Маршруты

| Метод | Путь            | Описание                          |
|-------|-----------------|-----------------------------------|
| GET   | `/`             | Список трат                       |
| GET   | `/add`          | Форма добавления                  |
| POST  | `/add`          | Сохранение траты, redirect на `/` |
| GET   | `/edit/{id}`    | Форма редактирования              |
| POST  | `/edit/{id}`    | Сохранение изменений              |
| POST  | `/delete/{id}`  | Удаление траты                    |
| GET   | `/static/...`   | Статические файлы (CSS)           |

## План развития

1. Категории трат и фильтрация (этап 4).
2. Регистрация и авторизация (этап 5).
3. Статистика и графики (этап 6).
4. Валидация, обработка ошибок, middleware (этап 7).
5. Экспорт в CSV, настройка через `.env` (этап 8).

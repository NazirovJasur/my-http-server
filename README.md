# 💰 Учёт личных трат (Go)

Учебный проект по веб-разработке на языке Go. Приложение позволяет вести учёт личных трат: добавлять, редактировать, удалять и просматривать список расходов. Проект разбит на этапы, каждый из которых добавляет новый функционал.

---

## 🚀 Запуск проекта

### Требования

- **Go** версии **1.27.1** или выше
- **Git** (для клонирования репозитория)

### Клонирование репозитория

```bash
git clone https://github.com/NazirovJasur/my-http-server.git
cd my-http-server
```

### Установка зависимостей

```bash
go mod tidy
```

---

### Запуск основного приложения (Этапы 3-5)

Полноценное приложение с HTML-шаблонами, SQLite, CRUD-операциями, категориями и авторизацией.

**Запуск (из корня проекта):**

```bash
go run ./cmd/server
```

**Что доступно:**

- `http://localhost:8080/register` — регистрация нового пользователя
- `http://localhost:8080/login` — вход в систему
- `http://localhost:8080/` — список трат (доступен только после входа)
- `http://localhost:8080/add` — форма добавления траты
- `http://localhost:8080/edit?id=1` — редактирование
- `http://localhost:8080/static/style.css` — статика

**Проверка работы (Сценарий):**

1. Зарегистрируйте нового пользователя.
2. Войдите в систему (появится сессионная кука).
3. Добавьте трату с выбором категории.
4. Проверьте работу фильтров по категории и датам.
5. Нажмите «Выйти» (доступ к списку трат закроется).

# 💰 Учёт личных трат

Учебное веб-приложение на Go для учёта личных расходов.
Сейчас реализован **этап 2**: HTML-интерфейс со списком трат и формой добавления. Данные хранятся в памяти и пропадают при перезапуске сервера.

## Возможности

- Просмотр списка трат в таблице (ID, сумма, описание, дата).
- Добавление траты через форму (сумма, описание, дата).
- После отправки формы выполняется redirect на список (Post/Redirect/Get), поэтому повторной отправки при обновлении страницы не происходит.
- Общий layout (шапка и подвал) для всех страниц.

## Технологии

- Go (версия не ниже 1.22, нужна для маршрутов вида `GET /add`)
- Стандартная библиотека: `net/http`, `html/template`
- HTML и CSS без фреймворков

## Запуск

Команды выполняются **из корня проекта** (где лежит `go.mod`), потому что пути к шаблонам и статике заданы относительно него.

```bash
go run ./cmd/server
```

После запуска откройте в браузере: <http://localhost:8080>

## Маршруты

| Метод | Путь          | Описание                     |
|-------|---------------|------------------------------|
| GET   | `/`           | Список трат                  |
| GET   | `/add`        | Форма добавления траты       |
| POST  | `/add`        | Сохранение траты, redirect на `/` |
| GET   | `/static/...` | Статические файлы (CSS)      |

## Ограничения текущего этапа

- Данные хранятся в срезе в памяти и не сохраняются между запусками.
- Нет редактирования и удаления трат.
- Нет категорий, авторизации и статистики.

## План развития

1. Хранение в SQLite через слой репозитория (этап 3).
2. Категории трат и фильтрация (этап 4).
3. Регистрация и авторизация (этап 5).
4. Статистика и графики (этап 6).
5. Валидация, обработка ошибок, экспорт в CSV, настройка через `.env` (этапы 7–8).

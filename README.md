# 💰 Учёт личных трат (Go)

Учебный проект по веб-разработке на языке Go. Приложение позволяет вести учёт личных трат: добавлять, редактировать, удалять и просматривать список расходов. Проект разбит на этапы, каждый из которых добавляет новый функционал.

## 🚀 Запуск проекта

### Требования

- **Go** версии **1.27.1** или выше
- **Git** (для клонирования репозитория)

### Клонирование репозитория

```bash
git clone https://github.com/NazirovJasur/my-http-server.git
cd my-http-server
```

### Установка зависимостей

```bash
go mod tidy
```

---

### Вариант 1: Простой HTTP-сервер (Этап 1)

Этот вариант демонстрирует базовый сервер на `net/http` с тремя маршрутами: `/`, `/about`, `/ping`.

**Запуск:**

```bash
go run Atap1.go
```

**Проверка:**

- http://localhost:8080/ — приветствие
- http://localhost:8080/about — описание проекта
- http://localhost:8080/ping — `pong` (только GET, иначе 405)

**Проверка через curl:**

```bash
curl -i http://localhost:8080/ping
curl -i -X POST http://localhost:8080/ping
```

---

### Вариант 2: Основное приложение (Этап 2/3)

Полноценное приложение с HTML-шаблонами, SQLite и CRUD-операциями.

**Запуск:**

```bash
go run main.go
```

или, если `main.go` находится в `cmd/server/`:

```bash
go run cmd/server/main.go
```

**Что доступно:**

- http://localhost:8080/ — список трат
- http://localhost:8080/add — форма добавления
- http://localhost:8080/edit?id=1 — редактирование
- http://localhost:8080/static/style.css — статика

**Проверка сохранения данных:**

1. Добавьте трату.
2. Остановите сервер (Ctrl+C).
3. Запустите снова.
4. Трата должна остаться в списке (данные в `expenses.db`).

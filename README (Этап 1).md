# HTTP-сервер на Go (этап 1)

Учебный HTTP-сервер на стандартной библиотеке `net/http`, без сторонних зависимостей.
Первый этап семестрового проекта «Учёт личных трат».

## Возможности

- Три маршрута: главная страница, описание проекта и проверка работоспособности.
- Маршрут `/ping` отвечает только на GET, на остальные методы возвращает `405 Method Not Allowed`.
- Неизвестные пути возвращают `404 Not Found`.

## Требования

- Go 1.22 или новее (в `go.mod` указана версия 1.27.1, при другой версии поправьте строку `go`).

## Структура проекта

```
.
├── Atap1.go    # обработчики и запуск сервера
└── go.mod      # модуль etap1
```

## Запуск

Из папки, где лежит `go.mod`:

```bash
go run .
```

Сервер запустится на <http://localhost:8080>.

## Маршруты

| Метод | Путь     | Ответ                                             |
|-------|----------|---------------------------------------------------|
| GET   | `/`      | 200, приветственный текст                         |
| GET   | `/about` | 200, описание проекта                             |
| GET   | `/ping`  | 200, `pong`                                       |
| другие| `/ping`  | 405, `method not allowed`                         |
| любой | прочие   | 404 Not Found                                     |

## Проверка через curl

```bash
curl -i http://localhost:8080/ping
# HTTP/1.1 200 OK ... pong

curl -i -X POST http://localhost:8080/ping
# HTTP/1.1 405 Method Not Allowed ... method not allowed

curl -i http://localhost:8080/unknown
# HTTP/1.1 404 Not Found
```

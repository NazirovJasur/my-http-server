# 💰 Учёт личных трат (этап 2)

Учебное веб-приложение на Go. Этап 2: HTML-интерфейс со списком трат и формой добавления.
Данные хранятся **в памяти** и пропадают при перезапуске сервера.

## Возможности

- Список трат в таблице (ID, сумма, описание, дата).
- Добавление траты через форму (сумма, описание, дата).
- После отправки формы выполняется redirect на список (Post/Redirect/Get), поэтому обновление страницы не отправляет форму повторно.
- Общий layout (шапка и подвал) для всех страниц.

## Технологии

- Go 1.22 или новее (нужна для маршрутов вида `GET /add`)
- Стандартная библиотека: `net/http`, `html/template`
- HTML и CSS без фреймворков

## Запуск

Команды выполняются **из корня проекта** (где лежит `go.mod`): пути к шаблонам и статике заданы относительно него.

```bash
go run ./cmd/server
```

Откройте в браузере: <http://localhost:8080>

## Маршруты

| Метод | Путь          | Описание                            |
|-------|---------------|-------------------------------------|
| GET   | `/`           | Список трат                         |
| GET   | `/add`        | Форма добавления                    |
| POST  | `/add`        | Сохранение траты, redirect на `/`   |
| GET   | `/static/...` | Статические файлы (CSS)             |

## Ограничения этапа

- Данные не сохраняются между запусками.
- Нет редактирования и удаления.
- Серверная проверка ввода минимальна (разбор суммы и даты).
